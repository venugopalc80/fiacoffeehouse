# FIA Coffeehouse Website

Luxury hospitality website concept for FIA Coffeehouse, Preston.

## Design direction
- Luxury editorial café aesthetic
- Coffeehouse, brunch and florals as the core brand pillars
- FIA's supplied menu is the source of truth for menu content
- Responsive desktop/mobile experience
- Functional booking, contact, gallery, navigation, Google Maps and Instagram CTAs

## Planned features
- Home
- Menu
- Leia Florals
- Events / private hire
- Gallery
- About
- Visit Us
- Book a Table
- Seasonal content
- Gift cards
- Mobile responsive navigation
